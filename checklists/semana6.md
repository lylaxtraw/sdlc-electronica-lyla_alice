# Checklist de Revisión

- [ ] **Funcionalidad:** Todos los Requisitos Funcionales (RF) están operativos en la URL pública (las credenciales demo están documentadas en el `README.md` si aplica).
- [ ] **Calidad y Despliegue:** El CI de GitHub Actions está en verde. La cobertura de código es ≥ 80%. El CD está desplegando correctamente los cambios en producción y las migraciones de Alembic se aplican con éxito.
- [ ] **Documentación Completa:** El proyecto cuenta con un `README.md` robusto, diagrama de arquitectura, al menos 2 ADRs documentados y el archivo `AI_LOG.md` consolidado con el aprendizaje total.
- [ ] **Presentación:** Existe un video demo grabado de entre 3 a 5 minutos, y la presentación técnica está ensayada para la defensa.
- [ ] **Dominio del Sistema:** El autor puede responder cualquier pregunta técnica razonable sobre la arquitectura, decisiones y líneas de código del proyecto sin necesidad de mirar notas.
